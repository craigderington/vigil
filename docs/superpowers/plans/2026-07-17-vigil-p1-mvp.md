# Vigil P1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a self-hosted, containerized HTTP uptime monitor that detects confirmed outages (immune to your own connection dropping), records incidents, and emails you on down/recovery — started with `docker compose up -d` and driven from a navy SolidJS dashboard.

**Architecture:** One Rust binary (`axum`) serving a REST API + SSE stream + the built SolidJS SPA, with a `tokio` check engine (scheduler → bounded worker pool → pure state machine → notifier) and an anchor "internet-sanity" gate that suppresses false alarms. State in SQLite (WAL) on a mounted volume. Email via `lettre` (rustls). Runs non-root; SMTP password supplied as a Docker secret.

**Tech Stack:** Rust 2021 (`tokio`, `axum` 0.7, `reqwest` 0.12 rustls, `lettre` 0.11 rustls, `sqlx` 0.8 sqlite, `serde`, `tracing`); SolidJS + Vite + TypeScript; SQLite; Docker + Docker Compose. Test: `cargo test`, `wiremock` for the prober, `vitest` for frontend units.

Full design: [`docs/superpowers/specs/2026-07-17-vigil-p1-mvp-design.md`](../specs/2026-07-17-vigil-p1-mvp-design.md). Blueprint: [`CLAUDE.md`](../../../CLAUDE.md).

## Global Constraints

- **Scope is P1 only.** HTTP(S) monitors only. No keyword/port/dns/ping/heartbeat/ssl monitor types, no charts/90-day bars/rollups, no SSL/domain tracking, no maintenance windows, no reports, no list view, no non-email channels, no auth. Do not build them.
- **Timestamps** are UNIX epoch **seconds** as `i64` everywhere (DB, DTOs, events).
- **TLS is rustls end-to-end.** `reqwest` with `default-features=false, features=["rustls-tls","json","gzip"]`; `lettre` with `default-features=false, features=["tokio1-rustls-tls","smtp-transport","builder"]`. No OpenSSL/`native-tls` anywhere; the runtime image ships no `libssl`.
- **SQLite pragmas:** every pooled connection sets `foreign_keys=ON` and `journal_mode=WAL`; DB is created with `auto_vacuum=INCREMENTAL`.
- **Runs as non-root** in the container; `/data` (the directory, for WAL sidecars) is owned by the app user.
- **The SMTP password is never** written to the DB, returned by any API, or logged. It is read once at startup from `/run/secrets/smtp_password` (dev fallback env `VIGIL_SMTP_PASSWORD`).
- **Defaults (verbatim):** interval floor `15s`; global probe concurrency `25`; confirmation threshold `3`; recovery threshold `1`; retry interval `30s`; expected status codes `200-299`; timeout `30s`; anchors `1.1.1.1:443,8.8.8.8:443`; notify cooldown `15` minutes; raw-check retention `30` days; bind `0.0.0.0:8080`; accent `#3FC8E4`; canvas `--bg-base:#06051e`.
- **Uptime/downtime derive from `incidents`, never from counting raw `checks`.** Empty window (no checks in range) renders `—`.
- **Commit after every task** (each task ends with a commit step). Conventional-commit messages.
- **Cargo workspace layout:** backend crate at `crates/vigil/`, frontend at `web/`, Docker/compose at repo root.

**State machine contract** (`crates/vigil/src/state.rs`):

```rust
use crate::models::*;

pub struct Thresholds { pub confirmation: i64, pub recovery: i64 }

/// What the caller must persist / act on after evaluate().
#[derive(Clone, Debug, PartialEq)]
pub struct Decision {
    pub next_status: Status,
    pub consecutive_failures: i64,
    pub consecutive_successes: i64,
    pub transition: Option<Transition>,
    pub use_retry_interval: bool, // true => reschedule at retry_interval, else normal interval
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Transition {
    ToDownOpenIncident,   // open incident + notify(Down)
    ToUpCloseIncident,    // close incident + notify(Recovered)
    ToUpNoIncident,       // UNKNOWN/PENDING -> UP with no prior open incident
    ToUnknown,            // entered UNKNOWN (fleet-wide); leave any open incident suspended
}

pub struct Inputs {
    pub current: Status,
    pub prev_confirmed: Status,   // last Up|Down before any Unknown (Pending if none)
    pub consecutive_failures: i64,
    pub consecutive_successes: i64,
    pub outcome_ok: bool,
    pub anchor: Connectivity,
    pub th: Thresholds,
}

pub fn evaluate(i: &Inputs) -> Decision; // pure, no I/O
```

```rust
pub fn evaluate(i: &Inputs) -> Decision {
    let (mut f, mut s) = (i.consecutive_failures, i.consecutive_successes);
    if i.outcome_ok {
        s += 1; f = 0;
        let recovered = matches!(i.current, Status::Down)
            || (matches!(i.current, Status::Unknown) && matches!(i.prev_confirmed, Status::Down));
        if recovered && s >= i.th.recovery {
            return Decision { next_status: Status::Up, consecutive_failures: 0,
                consecutive_successes: s, transition: Some(Transition::ToUpCloseIncident),
                use_retry_interval: false };
        }
        let to_up_fresh = matches!(i.current, Status::Pending)
            || (matches!(i.current, Status::Unknown) && !matches!(i.prev_confirmed, Status::Down));
        let trans = if to_up_fresh { Some(Transition::ToUpNoIncident) } else { None };
        return Decision { next_status: Status::Up, consecutive_failures: 0,
            consecutive_successes: s, transition: trans, use_retry_interval: false };
    }
    // failure
    f += 1; s = 0;
    if f < i.th.confirmation {
        return Decision { next_status: i.current.max_active(), consecutive_failures: f,
            consecutive_successes: 0, transition: None, use_retry_interval: true };
    }
    match i.anchor {
        Connectivity::Offline => Decision { next_status: Status::Unknown, consecutive_failures: f,
            consecutive_successes: 0, transition: Some(Transition::ToUnknown), use_retry_interval: false },
        Connectivity::Online => {
            let already_down = matches!(i.current, Status::Down)
                || (matches!(i.current, Status::Unknown) && matches!(i.prev_confirmed, Status::Down));
            let trans = if already_down { None } else { Some(Transition::ToDownOpenIncident) };
            Decision { next_status: Status::Down, consecutive_failures: f, consecutive_successes: 0,
                transition: trans, use_retry_interval: false }
        }
    }
}
```

```dockerfile
 && mkdir -p /data && chown app:app /data

COPY --from=web /web/dist /srv/web-dist
```
