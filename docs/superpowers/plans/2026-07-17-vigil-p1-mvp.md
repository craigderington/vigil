# Vigil P1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Revision:** v2 — reordered so the shared backbone (events, AppState, notify transport, test helpers) lands before the engine; compile-blockers and the `prev_confirmed` gap fixed from the plan review.

**Goal:** Ship a self-hosted, containerized HTTP uptime monitor that detects confirmed outages (immune to your own connection dropping), records incidents, and emails you on down/recovery — started with `docker compose up -d` and driven from a navy SolidJS dashboard.

**Architecture:** One Rust binary (`axum`) serving a REST API + SSE stream + the built SolidJS SPA, with a `tokio` check engine (scheduler → bounded worker pool → pure state machine → notifier) and an anchor "internet-sanity" gate that suppresses false alarms and drives fleet-wide UNKNOWN. State in SQLite (WAL) on a mounted volume. Email via `lettre` (rustls). Runs non-root; SMTP password supplied as a Docker secret.

**Tech Stack:** Rust 2021 (`tokio`, `axum` 0.7, `reqwest` 0.12 rustls, `lettre` 0.11 rustls, `sqlx` 0.8 sqlite, `serde`, `anyhow`, `async-trait`, `tokio-stream`, `tracing`); SolidJS + Vite + TypeScript; SQLite; Docker + Docker Compose. Test: `cargo test`, `wiremock` for the prober, `vitest` for frontend units.

Full design: [`docs/superpowers/specs/2026-07-17-vigil-p1-mvp-design.md`](../specs/2026-07-17-vigil-p1-mvp-design.md). Blueprint: [`CLAUDE.md`](../../../CLAUDE.md).

## Global Constraints

- **Scope is P1 only.** HTTP(S) monitors only. No keyword/port/dns/ping/heartbeat/ssl types, no charts/90-day bars/rollups, no SSL/domain tracking, no maintenance windows, no reports, no list view, no non-email channels, no auth. Do not build them.
- **Timestamps** are UNIX epoch **seconds** as `i64` (`Ts`) everywhere (DB, DTOs, events).
- **TLS is rustls end-to-end.** `reqwest` `default-features=false, features=["rustls-tls","json","gzip"]`; `lettre` `default-features=false, features=["tokio1-rustls-tls","smtp-transport","builder"]`. No OpenSSL/`native-tls`; the runtime image ships no `libssl`.
- **SQLite pragmas:** every pooled connection sets `foreign_keys=ON` and `journal_mode=WAL`; DB created with `auto_vacuum=INCREMENTAL`.
- **Runs as non-root**; `/data` (the directory, for WAL sidecars) owned by the app user.
- **The SMTP password is never** written to the DB, returned by any API, or logged. Read once at startup from `/run/secrets/smtp_password` (dev fallback env `VIGIL_SMTP_PASSWORD`), captured inside the SMTP transport — never on `AppState`.
- **`prev_confirmed` is derived, not stored:** at evaluation time, an open (unresolved) incident ⇒ `prev_confirmed = Down`, else `Up`. No column.
- **Defaults (verbatim):** interval floor `15s`; concurrency `25`; confirmation `3`; recovery `1`; retry `30s`; expected codes `200-299`; timeout `30s`; anchors `1.1.1.1:443,8.8.8.8:443`; notify cooldown `15` min; retention `30` days; bind `0.0.0.0:8080`; accent `#3FC8E4`; canvas `--bg-base:#06051e`.
- **Uptime/downtime derive from `incidents`, never from raw `checks`.** Empty window (no checks in range) renders `—`.
- **Commit after every task.** Conventional-commit messages.
- **Layout:** backend crate `crates/vigil/`, frontend `web/`, Docker/compose at repo root.

```rust
use sqlx::sqlite::{SqlitePoolOptions, SqliteConnectOptions, SqliteAutoVacuum, SqliteJournalMode};
use std::str::FromStr;
pub async fn connect(db_path: &str) -> anyhow::Result<sqlx::SqlitePool> {
    let opts = SqliteConnectOptions::from_str(&format!("sqlite://{db_path}"))?
        .create_if_missing(true).foreign_keys(true)
        .journal_mode(SqliteJournalMode::Wal).auto_vacuum(SqliteAutoVacuum::Incremental);
    let pool = SqlitePoolOptions::new().max_connections(5).connect_with(opts).await?;
    run_migrations(&pool).await?; Ok(pool)
}
async fn run_migrations(pool: &sqlx::SqlitePool) -> anyhow::Result<()> {
    sqlx::query("CREATE TABLE IF NOT EXISTS schema_migrations (version INTEGER PRIMARY KEY, applied_at INTEGER NOT NULL)")
        .execute(pool).await?;
    let done: Option<i64> = sqlx::query_scalar("SELECT version FROM schema_migrations WHERE version=1")
        .fetch_optional(pool).await?;
    if done.is_none() {
        let sql = include_str!("../migrations/0001_init.sql"); // path is relative to src/db.rs
        let mut tx = pool.begin().await?;
        for stmt in sql.split(';') { let s = stmt.trim(); if !s.is_empty() { sqlx::query(s).execute(&mut *tx).await?; } }
        sqlx::query("INSERT INTO schema_migrations (version,applied_at) VALUES (1,0)").execute(&mut *tx).await?;
        tx.commit().await?;
    }
    Ok(())
}
```
(The migration file must not `CREATE TABLE schema_migrations` again — the runner owns it. Keep statements semicolon-terminated, no semicolons inside — fine for this DDL.)
