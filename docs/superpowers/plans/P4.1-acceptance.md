# Vigil P4.1 (Heartbeat / Push Monitors) — End-to-End Acceptance

**Date:** 2026-07-18 · **Branch:** `feat/p4-heartbeat` (base `aeed38b`, 13 commits)

Verifies the P4.1 Definition of Done: the inverse "heartbeat/push" monitor — a job checks in at a
unique `/ping/:token` URL; if it doesn't within `interval + grace`, the monitor goes DOWN (fires
`heartbeat_missed`) and recovers on the next ping.

**All P4.1 DoD items verified.** Three per-task adversarial reviews caught (and fixed) real bugs a
naive implementation would ship: a SQLite write-lock leak (raw `BEGIN IMMEDIATE` → `begin_with`
